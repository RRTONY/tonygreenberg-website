## 1. Project bootstrap

- Next.js 16 (App Router, Turbopack), TypeScript, Tailwind CSS v4, shadcn/ui (Radix base) — set up
  inside this same repo at `web/`, not a disconnected new project. Legacy `client/`, `server/`,
  `shared/` untouched and still running.
- Read Next.js 16's bundled breaking-changes docs before writing code (Promise `params`,
  `proxy.ts` replacing `middleware.ts`, `images.remotePatterns`, etc.) — documented in
  `web/CLAUDE.md` / `web/CONTRIBUTING.md` so future sessions don't rediscover these the hard way.
